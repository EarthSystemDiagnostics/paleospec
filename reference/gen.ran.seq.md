# Generate Random Numbers Without Affecting the State of .Random.seed

Generate Random Numbers Without Affecting the State of .Random.seed

## Usage

``` r
gen.ran.seq(n, nser, s)
```

## Arguments

- n:

  number of observations

- nser:

  number of replicate series

- s:

  NA or integer, passed to set.seed() if integer

## Value

a matrix
